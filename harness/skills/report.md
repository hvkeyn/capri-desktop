# Report

The file is the deliverable. The sentence in the chat is a note on top of it.

- **Lead with the answer**, then the parts. Someone who reads only the first paragraph should know what
  happened.
- **One item, one block**: what happened (one or two sentences), who says it, the date and time, the
  address. The same shape every time, so the eye can skip.
- **Group by what they asked for**, not by the order you found things: "мировые" and "российские" if that
  is the question.
- **Time is part of the fact**: "as of 2026-11-08 21:40 UTC". Mark anything older than the window asked
  for, or leave it out.
- **Say what did not answer**: a short block at the end — which source refused, which claim stayed
  single-sourced, which part is not checked. That block is why the rest can be trusted.
- **No filler.** No "в современном мире", no "стоит отметить", no apology at the top. If there is little,
  a short honest file beats a long padded one.
- **Markdown, plain**: headings, lists, bold for names and numbers. A table only when the columns are real
  (date, source, what).
